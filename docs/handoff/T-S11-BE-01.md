# Handoff: T-S11-BE-01 – GenAI Quiz & Flashcard Service (Batched)

## 1. Tóm tắt công việc
- **Cấu hình hệ thống (sys_setting):** Tạo entity `SystemSetting`, bảng `sys_setting` theo DEC-12, hiện thực `ISystemSettings` (`SystemSettingsService`). Cung cấp API `GET /api/v1/admin/settings` và `PUT /api/v1/admin/settings` cho Admin quản trị `aiDailyQuota` và `aiLlmProvider`.
- **Hạn mức AI người dùng (ai_user_daily_quota):** Tạo entity `AiUserDailyQuota`, bảng `ai_user_daily_quota`. Cung cấp API `GET /api/v1/ai/quota` và `IAiContract.GetDailyQuota`. Kiểm tra và khấu trừ quota tự động khi tạo job (trả `429 AI_QUOTA_EXCEEDED` khi hết lượt).
- **External LLM Client (Gemini API):** Hiện thực `ILlmClient` (`GeminiLlmClient`) gọi Google Gemini REST API với timeout 30s, circuit breaker (ngắt mạch 30s sau 3 lỗi liên tiếp) và fallback simulation khi không có khóa API để phục vụ môi trường test/dev.
- **Xử lý Job bất đồng bộ:** API `POST /api/v1/courses/{courseId}/ai/quiz-jobs` và `POST /api/v1/courses/{courseId}/ai/flashcard-jobs` trả HTTP `202 Accepted` kèm `jobId`. Hàng đợi `IAiJobQueue` (Channel) cùng `AiJobBackgroundWorker` chạy nền gọi LLM, giải mã JSON và import bản nháp. API `GET /api/v1/ai/jobs/{id}` phục vụ polling 2s.
- **Tích hợp Content Module:** Hiện thực `IContentContract.ImportAiGeneratedQuestions`, `ImportAiGeneratedFlashcards` và `GetChapterTextForAi` trong `ContentContractService`. Đảm bảo nội dung sinh ra luôn ở trạng thái `DRAFT` / `PENDING` (Human-in-the-loop).

## 2. Kiểm thử
- Tạo dự án `AI.UnitTests` với 11 bài kiểm thử bao phủ toàn bộ vòng đời job, quota, circuit breaker, admin settings và contracts. Toàn bộ `11/11` tests đều PASS.
- Build toàn bộ solution với `dotnet build backend/BrainMemo.sln` đạt 0 warning, 0 error.
